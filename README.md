GLASSWERK STUDIO — responsywna strona internetowa

Wszystkie pliki są w jednym miejscu, bez podfolderów.

Jak uruchomić lokalnie:
1. Pobierz wszystkie pliki do jednego folderu.
2. Otwórz index.html w przeglądarce.
3. Nie zmieniaj nazw plików graficznych, bo index.html odwołuje się do nich bezpośrednio.

Publikacja na GitHub Pages:
1. Prześlij wszystkie pliki z tego pakietu do głównego katalogu repozytorium glasswerk-studio.
2. W GitHub przejdź do Settings → Pages.
3. W sekcji Build and deployment wybierz Deploy from a branch, gałąź main i folder /(root), następnie Save.
4. Po zakończeniu publikacji GitHub pokaże adres strony w sekcji Pages.

Zdjęcia, logo PNG/SVG i index.html muszą pozostać w tym samym katalogu.
